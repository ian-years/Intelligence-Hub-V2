# ADR-0008: 前端信息架构与孟菲斯设计令牌

- **状态**：Accepted
- **日期**：2026-09-22
- **决策人**：用户 + Qoder
- **相关**：Q8、`docs/specs/ui-tokens.md`、ADR-0003（前端栈）

## 背景

V1 前端是单页应用（`launcher/index.html`），所有功能堆在一个页面里，靠 tab 切换。痛点：

- 信息密度高但层次不清
- 没有设计系统，颜色/间距/字体硬编码
- 改一个组件影响全局
- 没有响应式（V1 默认桌面用）

V2 要：
1. 孟菲斯风格（80 年代设计运动：亮色块、粗黑边、硬阴影、几何形状、不对称布局、图案背景）
2. 七页信息架构（Dashboard / Feed / Video Detail / Creators / Tasks / Settings / Preflight）
3. 设计令牌作为 V3 契约（V3 换框架可复用）
4. 配置面板按 JSON Schema 自动渲染

## 决定

### 信息架构

```
┌─────────────────────────────────────────────────────────────────┐
│  顶栏：当前数据目录 · 桥状态灯 · 运行中任务数 · 全局搜索         │
├──────────────┬──────────────────────────────────────────────────┤
│  侧边导航    │              主区域                              │
│  （孟菲斯    │                                                  │
│   几何图标） │                                                  │
│  ◆ Dashboard │                                                  │
│  ▲ Feed      │                                                  │
│  ● Creators  │                                                  │
│  ■ Tasks     │                                                  │
│  ~ Settings  │                                                  │
└──────────────┴──────────────────────────────────────────────────┘
```

**侧边导航 vs 顶部导航**：选侧边。理由：孟菲斯那种几何图标在竖向排列时更有节奏感，且主区域更宽，适合 Feed 瀑布流。

### 七页 + 孟菲斯落点

1. **Dashboard / 总览** — 四张平台健康卡片（每个平台一个几何形状代表：抖音=三角、B站=圆、小红书=方、YouTube=波浪线），卡片用硬阴影 + 粗黑边；下方是「最近 5 次任务」时间线 + 「最新 10 条作品」横向滚动条。背景：圆点阵 SVG 平铺。

2. **Feed / 情报流** — 视频卡片瀑布流，每张卡片显示封面、标题、博主、平台徽章（几何形状 + 平台色）、时长、隐藏按钮（×）；顶部过滤栏（平台 / 博主 / 日期 / 是否已转写）+ 排序（发布时间 / 播放量 / 点赞）。背景：斜条纹。**虚拟滚动**（`@tanstack/react-virtual`）。

3. **Video Detail / 作品详情** — 左侧视频播放器（HTML5 `<video>` 直接播 `data/media/...`），右侧 metadata + 口播稿（带时间戳分段，点击跳播放位置）+ 「相关博主」卡片。背景：波浪线。

4. **Creators / 博主库** — 表格视图（昵称、平台、跟踪开关、粉丝数、最近收录时间、操作）+ 「添加博主」按钮（粘贴 URL → 后端走 `parse_creator_url`）+ 「爆款回溯」按钮（V1 §7.22 的 `BackfillTask`，按 URL 直接定位，不退化全库扫描）。背景：几何碎片。

5. **Tasks / 任务中心** — 上半部分「可用任务」卡片墙（每张卡片：任务名 + 描述 + 涉及平台徽章 + 「运行」按钮，点开是参数表单），下半部分「运行历史」表格（点击进详情页看实时事件流 + 清单 + 取消按钮）。背景：圆点阵 + 三角碎片。

6. **Settings / 配置** — 左侧二级导航（平台 / 全局 / 数据目录 / ASR 引擎 / 关于），右侧表单。平台配置页：每个平台一张卡片，顶部是巨型开关（孟菲斯风格：粗黑边的拨动开关，开 = 亮色填充，关 = 灰），下方按 JSON Schema 自动渲染参数字段。背景：棋盘格。

7. **Preflight / 环境预检**（Settings 的子页） — V1 §4.1 那张表的可视化版：每一项依赖（ffmpeg / node / Chrome / yt-dlp / playwright / SenseVoice 模型 / cookies 文件 / 桥连通性）一行，状态徽章（绿/黄/红）+ 「如何修复」展开。背景：斜条纹。

### 孟菲斯设计令牌

完整令牌见 `docs/specs/ui-tokens.md`。关键决策：

**色板**：
- 主色：电光蓝 `#0066FF` / 珊瑚红 `#FF6B6B` / 柠檬黄 `#FFD93D` / 薄荷绿 `#6BCB77` / 烈粉 `#FF3D9A`
- 中性：漆黑 `#0A0A0A` / 米白 `#FAF7F2` / 雾灰 `#D8D8D8`
- 每个平台一个主色 + 一个几何形状：抖音=烈粉+三角、B站=电光蓝+圆、小红书=珊瑚红+方、YouTube=柠檬黄+波浪

**形状语言**：
- 粗黑描边 `3px`
- 硬阴影 `6px 6px 0 ink-black`（无模糊）
- **直角，不要圆角**（孟菲斯要硬朗）
- 几何形状：三角 / 圆 / 方 / 波浪线 / 锯齿

**图案背景**：SVG 平铺（圆点阵、斜条纹、波浪线、几何碎片、棋盘格），用 CSS `background-image` 内联 data URI，每个页面一种图案。

**排版**：
- 标题：Archivo Black（粗几何无衬线）
- 副标题：Space Grotesk
- 正文：Inter
- 代码/日志：JetBrains Mono

**动效**：
- 按钮按下"压扁→弹回"（`scale(0.95) → scale(1.0) 150ms cubic-bezier(0.34, 1.56, 0.64, 1)`）
- 模态框"几何形状从四角飞入"（250ms）
- 加载指示器用旋转三角 / 跳动圆点 / 摇摆波浪线（**不用圆环**）

**布局**：**故意不对称**，元素错位、压叠、超出网格，但要保留可读性。Feed 虚拟滚动要求卡片高度可预测，所以"错位"收敛到网格内。

### 组件底座分工

- **shadcn/ui** 提供无障碍的：Dialog / Select / Switch / Combobox / Tabs / Tooltip / Toast / Form
- **自定义孟菲斯组件**：`<MemphisCard>` / `<MemphisButton>` / `<PlatformBadge>` / `<ShapeIcon>` / `<HardShadowPanel>` / `<PatternBackground>` / `<StatusLight>`
- **平台形状图标**：用 SVG 组件，每个平台一份（`<DouyinTriangle>` / `<BiliCircle>` / ...），可染色

### 暗色模式

**V2.0 只做亮色**，暗色留 V2.1（如果有需求）。理由：孟菲斯风格本来就以亮色 + 米白底为主，做暗色版要重调色板，不是 V2.0 优先级。

### 高级字段折叠

平台配置里"高级"字段（如 B站 `cookie_variant_order`、抖音 `ytdlp_cookie_priority`）默认折叠，schema 里用 `ui:advanced` 标记。详见 ADR-0007。

## 后果

**好处**：
- 设计令牌（CSS 变量 + JSON）是 V3 契约：V3 即使换 Vue/Svelte/Solid，色板与间距系统直接复用
- 七页信息架构清晰，每页职责单一
- shadcn/ui 的复制粘贴模式 = 我们拥有组件源码，可以彻底改成孟菲斯
- 虚拟滚动让 Feed 页上千条作品不卡

**代价**：
- 孟菲斯风格细节多（几何形状、硬阴影、图案背景、动效），实现成本比"普通后台模板"高
- 设计令牌要维护两份（CSS 变量 + JSON），用脚本生成保持一致
- 虚拟滚动要求卡片高度可预测，孟菲斯的"故意错位"要收敛

**对 V3 的意义**：
- `tokens.json` = UI 契约。V3 换框架直接复用
- 组件 = 实现，可弃；令牌 + 类型 + 行为契约 = 规范，保留
- 七页信息架构是用户契约，V3 沿用
