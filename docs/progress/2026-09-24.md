### 真机验到的（本机 Chrome + Playwright 1.63，都是量出来的）

- `pytest -m real_network tests/integration/test_bridge_health.py` → **1 passed 7.6s**：
  `python -m intelligence_hub_v2.bridge.server --headless` 起服务 → 真 `BridgeClient` 连上 →

  → `/cookies` 交出列表 → `/health` 的 `page_url` 真的是那一页。
- **自愈真验**（一次性探针脚本，不是常驻用例）：按 profile 路径捞出并杀掉桥拉起的 **8 个 chrome 进程** →
  `/health` 回 **503**、`page_url` 空、`last_page_url` 只当线索；下一条 `/evaluate` **2.1 秒**成功、
  `restarts=1`、两次 `/health` 的 `profile` 逐字符相同。
